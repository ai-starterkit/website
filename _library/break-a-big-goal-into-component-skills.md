---
title: "Break a big goal into component skills"
kind: prompt
part: Outcomes
order: 3
description: "Create · Finds the knowledge and skills hiding inside a broad course goal."
prompt: |-
  Course goal: [goal].
  Students: [who they are and what they already know].

  Help me break this goal into the smaller pieces of knowledge and skill students need to reach it.
  1. List the components: concepts to understand, procedures to carry out, judgments to make. Note which ones these students likely already have.
  2. Show how the components build toward the full performance.
  3. Flag components that are easy to overlook, such as deciding when a method applies, checking one's own work, or common misconceptions.
  4. Suggest which components deserve their own learning objective and which can be folded into others.

  Keep the full goal intact; don't shrink it to what's easy to assess. Mark anything a subject expert should confirm.
---
