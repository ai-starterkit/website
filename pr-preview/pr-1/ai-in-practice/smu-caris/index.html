Singapore Management University

CARIS 2.0: AI Analytics for Student Course Feedback

  • Stage: 3 Piloting & Capability Building
  • Scope: Teaching, Learning, and Assessment Strategies
  • Scale: Single-tool pilot

What it is

CARIS 2.0 was an AI-powered analytics dashboard developed to help instructors make sense of qualitative student course feedback. The system used LLMs to generate summary themes and personalised recommendations, and presented results in a PowerBI interface where instructors could filter comments by survey item or theme. A Copilot for PowerBI feature was also available, allowing instructors to query their feedback data using natural language. The project was initiated by the Centre for Teaching Excellence (CTE) in close coordination with Integrated Information Technology Services (IITS).

Problem addressed

Instructors received large volumes of qualitative feedback at the end of each term with no practical way to make sense of it all. CARIS 2.0 was the next iteration of an earlier custom ML-based system, upgrading it with LLM capability and an improved interface designed to provide more personalised and actionable insights.

How it was built

The project was built on the university's existing data platform and PowerBI infrastructure, requiring no new systems. Course feedback was collected through the university's feedback system, shared with a common data platform, and processed through a data pipeline using LLMs to generate themes, recommendations, and comment classifications. The processed data was stored and retrieved when instructors accessed the PowerBI interface. CTE led the interface design; IITS led the backend, data handling, and processing.

Cost & resources

The only direct cost was LLM API usage. The project used existing university data and analytics infrastructure. Staff time was diverted from both CTE and IITS.

Outcomes

The project was still in piloting at the time of submission, with no proven outcomes yet. Anticipated benefits included decreased operating costs and complexity compared to the previous custom ML model, and more personalised recommendations for instructors based on recurring themes in student feedback.

Risks

Three risks were identified. First, course feedback data was highly sensitive, so access controls limited each instructor to their own data, held only on IITS-approved platforms. Second, to counter LLM hallucinations, prompts were tuned on a benchmarking dataset, instructors could trace AI outputs to source comments, and reminders encouraged vigilance. Third, summaries risked being used in appraisals, mitigated by the same access controls limiting instructors to their own data.
